# VisuaLens-Photography-Portfolio

A stunning, fully responsive photography portfolio website built with **HTML**, **Tailwind CSS**, and **Vanilla JavaScript** — featuring a masonry gallery, category filters, hover zoom micro-interactions, and a full-screen lightbox modal.

---

## 🌐 Live Preview

> Open `index.html` in any modern browser — no build step required.

---

## ✨ Features

| Feature | Details |
|---|---|
| 📸 **Masonry Gallery** | Multi-column responsive CSS `columns` layout — 4 → 3 → 2 → 1 columns across breakpoints |
| 🔍 **Category Filters** | Dynamically toggle photo collections: All, Nature, Portrait, Architecture, Street, Abstract |
| 🔎 **Hover Zoom** | Smooth `scale` transform on each card with golden border glow and overlay reveal |
| 🖼️ **Lightbox Modal** | Full-screen preview with hi-res image loading, EXIF metadata, prev/next navigation, keyboard arrows, touch swipe & ESC to close |
| 📱 **Fully Responsive** | Mobile-first design — hamburger nav, stacked layouts, touch-friendly interactions |
| 🎨 **Dark Aesthetic UI** | Custom dark palette with gold accent (`#C8A96E`), animated hero blobs, grid overlay, scroll-reveal |
| 🧭 **Sticky Navbar** | Transparent → frosted-glass on scroll with active section highlighting |
| 📧 **Contact Form** | Live validation, project-type selector, simulated send with success state |
| ⚡ **No Dependencies** | Zero build tools — just Tailwind CDN + Vanilla JS |

## 🗂️ Project Structure

```
VisuaLens Photography Portfolio/
├── index.html      # Full page markup (navbar, hero, gallery, about, contact, lightbox)
├── style.css       # Custom styles extending Tailwind (masonry, filters, lightbox, animations)
├── app.js          # All interactivity — gallery data, filters, lightbox, form, scroll effects
└── README.md       # This file
```

---

## 🛠️ Skills Learned

- **Gallery Layout** — CSS `columns` masonry, `break-inside: avoid`, responsive column counts
- **CSS Grid & Flexbox** — section layouts, navbar, card overlays
- **Image Styling** — `object-fit`, aspect ratios, lazy loading, hover transforms
- **Responsive Design** — Tailwind breakpoints (`sm:`, `md:`, `lg:`), mobile-first approach
- **JavaScript Filters** — dynamic DOM manipulation, category toggling with animation
- **IntersectionObserver** — scroll-reveal and active nav highlighting
- **Lightbox Pattern** — modal state, keyboard/touch navigation, hi-res image swapping
- **Form Validation** — client-side validation with visual feedback

## 🚀 Getting Started

No installation needed.

```bash
# Clone the repo
git clone https://github.com/abrarjahinzihan/VisuaLens-Photography-Portfolio.git

# Open in browser
cd VisuaLens-Photography-Portfolio
start index.html       # Windows
open index.html        # macOS
xdg-open index.html    # Linux
```
